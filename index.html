إدارة IP الحاسبات

كمدير نظام، يمكنك:

  • تسجيل الدخول بأي حساب (تجاوز قيود IP تلقائياً)
  • تعيين IP لكل حاسبة عند إضافتها أو تعديلها
  • تغيير IP أي موظف من جدول الموظفين
  • الحاسبة لا تستطيع الدخول بدون IP مُدخل منك
  • إذا تركت IP فارغاً، لن يتمكن الحساب من الدخول
